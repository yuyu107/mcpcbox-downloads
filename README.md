# MCPCBox Downloads

用于研究、修复和替代多玩我的世界盒子 PC 版已经失效的资源、组件及游戏文件下载接口。

## 当前目标

- 修复 Java 运行环境下载入口
- 修复游戏版本 JSON 获取流程
- 调查纯净版游戏列表接口
- 保存替代下载源的 MD5 与 SHA-256 校验值
- 为本地皮肤管理器提供配套文件与说明

## 已确认的旧 Java 下载项

| 文件 | 原程序内置 MD5 |
| --- | --- |
| `jre_7_windows.7z` | `28640ba60fc62f7149124d3522aac9dd` |
| `java_7_8_v32.7z` | `07685aa514748192314591f21b40b01e` |
| `Java_7_8_V64.7z` | `0aae6a0b8a2049abc80afa193bd64ecc` |

旧下载源已经失效。替代文件需要同时满足盒子要求的目录结构，并在修改程序时同步更新下载地址和 MD5。

## 游戏版本 JSON

盒子的启动模块能够读取标准 Minecraft 版本 JSON 中的主要字段，包括：

- `downloads`
- `libraries`
- `assets`
- `minecraftArguments`

当盒子的 JSON 缓存缺失时，它仍可能访问旧版下载地址。计划增加本地 JSON 同步或当前版本清单适配。

## 关于 Java 文件

目前找到的旧运行环境包含 Oracle Java 7 和 Oracle Java 8 Update 60。仓库暂不公开分发这些二进制文件。后续应先确认再分发许可，或改用许可证允许公开再分发、且与目标系统兼容的运行环境。
